## Featured Projects

### Employee Scheduler

A full-stack workforce scheduling application with administrator and employee dashboards. A deterministic greedy algorithm generates shift suggestions using employee availability, existing assignments, and weekly-hour limits. Optional Groq integration turns natural-language staffing instructions into editable requirements, with administrator review before applying and publishing shifts.

**Java · Spring Boot · React · TypeScript · PostgreSQL · REST APIs**

[Source code](https://github.com/Folariin/employee-scheduler)

**Java · Spring Boot · Spring Security · React · PostgreSQL**
